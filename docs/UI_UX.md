## 1. 设计定位

### 1.1 产品类型与工作模式

MomoCode 是**产品型界面**，不是营销页。用户每天打开它是为了：

- **Monitor**：今天有多少到期复习、近期表现如何。
- **Decide**：现在该复习、自由练习，还是补某个薄弱技能。
- **Operate**：在训练工作区完成识别/编码/纠错并提交。
- **Compare**：在 Analytics 对比不同训练类型、技能与时间范围的表现。
- **Configure**：设置时区、复习上限、OJ 账号。

因此布局优先级是：**状态清晰 > 操作路径短 > 信息密度可控 > 视觉表现**。

### 1.2 设计原则

1. **五秒可回答“现在做什么”**：Dashboard 首屏必须出现今日复习量与主操作。
2. **训练时减少干扰**：工作区隐藏导航与营销内容，只保留任务、作答、提示、计时、提交。
3. **证据可解释**：每个分数/结论都能看到来源、样本量与时间范围。
4. **不把 FSRS 当能力分**：界面只显示“下次复习”，不显示 Stability/Difficulty。
5. **不把一次 AC 叫“掌握”**：结果页用“本次结果/本次证据”，不用“已掌握”。
6. **状态完整**：每个页面都设计加载、空、错误、离线、无数据、禁用状态。
7. **键盘可用**：所有流程不依赖鼠标；焦点可见；弹窗焦点陷阱与恢复。
8. **颜色不是唯一信号**：正确/部分/错误同时用图标 + 文案 + 颜色。

### 1.3 视觉方向（已确认）

| 项 | 决定 |
|---|---|
| 视觉风格 | **夜间工业控制台**：近黑炭灰背景、低饱和深色卡片、细边框、橙色作为唯一高亮；大标题、紧凑大写标签、数据仪表。全站不使用阴影，靠边框与层级色阶表达深度；标签越靠上层，底色与描边越浅。避免通用蓝紫渐变和“黑底终端绿”。 |
| 主色 | 橙色 `accent`（约 `oklch(0.68 0.2 38)`），用于主操作、当前导航、关键数字、进度与焦点。 |
| 辅助色 | 冷灰/钢灰中性阶；成功绿、警告琥珀、错误红仅用于语义状态。 |
| 参考方向 | 深色能源仪表盘（大标题 + 橙色流向/仪表）、深色 SaaS 项目板（侧栏、卡片、橙色强调）；仅参考视觉语言，不复制内容。 |
| 字体 | UI：Segoe UI Variable / 系统中文字体；代码：JetBrains Mono / Cascadia Code。标题使用紧凑字距与高字重。 |
| 界面密度 | 紧凑但可读：UI 基础字号 14px；卡片 14–16px 圆角；训练工作区更紧凑。 |
| 主题 | **默认深色**；保留浅色切换，两套都需 WCAG AA。 |
| 需要避免 | 蓝紫渐变、纯白大卡片、荧光色、满屏圆角药丸、只靠颜色表达状态、把 FSRS 参数做成能力分数。 |

> 主色与对比度在阶段 7 用实际 token 验证；若 `accent` 上的白字不足 4.5:1，改用 `accent-strong` 或深色文字。

## 2. 信息架构与导航

### 2.1 一级导航

| 导航 | 路由 | 作用 | 是否显示到期徽标 |
|---|---|---|---|
| Dashboard | `/` | 今日状态与主操作 | 是（待复习数） |
| Algorithm Library | `/library` | 浏览/检索算法与技能 | 否 |
| Smart Review | `/review` | 到期复习队列 | 是 |
| Free Practice | `/practice` | 自选任务练习 | 否 |
| Analytics | `/analytics` | 学习分析 | 否 |
| Settings | `/settings` | 账号、偏好、OJ | 否 |

上下文路由：

- 算法详情：`/library/algorithms/:algorithmSlug`
- 技能详情：`/library/skills/:skillSlug`
- 训练工作区：`/practice/sessions/:sessionId`
- 训练结果：`/practice/sessions/:sessionId/result`
- 登录/注册：`/login`、`/register`

### 2.2 应用外壳

```text
┌──────────────────────────────────────────────────────────────┐
│ Sidebar 240px │ TopBar: 页面标题 / 全局搜索 / 主题 / 用户菜单 │
│               ├──────────────────────────────────────────────┤
│ Dashboard     │                                              │
│ Library       │              页面内容区                       │
│ Review  (12)  │              max-width 1440                  │
│ Free Practice │              padding 24–32                    │
│ Analytics     │                                              │
│ Settings      │                                              │
│               │                                              │
│ 用户菜单       │                                              │
└──────────────────────────────────────────────────────────────┘
```

规则：

- 桌面 ≥1280px：侧栏展开 240px；1024–1279px：侧栏收为 72px 图标（悬停显示 label）；<1024px：侧栏变抽屉，顶部出现菜单按钮。
- 训练工作区不使用该外壳，使用独立的“专注模式”顶栏。
- 内容区最大宽度 1440px；长文（题面、技能说明）正文宽度限制 68–76ch。
- 全局搜索只搜算法/技能/任务标题，不搜用户数据；`Ctrl/Cmd + K` 打开。

### 2.3 路由守卫

- 未登录访问受保护路由 → 跳转 `/login?redirect=<原路径>`。
- 已登录访问 `/login`、`/register` → 跳转 `/`。
- 404 → 独立 Not Found 页面，提供“返回 Dashboard”。
- 403/资源不属于当前用户 → 统一“无权访问”页面，不泄露资源是否存在。

## 3. 页面设计

> 每页包含：目标、桌面布局、信息、操作、状态、移动端。状态统一遵循第 4 节。

### 3.1 登录 / 注册

**目标**：用最少步骤进入产品；错误信息可恢复。

**桌面布局**

- 左右分栏：左侧品牌区（产品名、一句话定位、三条价值点），右侧表单卡片（宽 380–420px）。
- 移动端：单列，品牌区缩为顶部标题。

**登录表单**

- 字段：邮箱、密码。
- 主操作：`登录`（按钮 loading 时显示“正在登录”）。
- 次操作：`创建账号` 链接。
- 错误：
  - 401：`邮箱或密码不正确`（不区分具体原因）。
  - 429：`尝试次数过多，请 60 秒后再试`，按钮倒计时禁用。
  - 网络错误：`无法连接服务器，请检查网络后重试`。
- 成功：跳转 `redirect` 或 `/`。

**注册表单**

- 字段：邮箱、密码、确认密码、显示名（可选）。
- 密码规则实时提示：至少 8 位；不强制复杂字符，但提示长度。
- 错误：邮箱已存在、两次密码不一致、格式错误。
- 说明：MVP 不发送验证邮件；文案不得暗示已发送。
- 成功：自动登录并进入 Dashboard。

**状态**

- Loading：按钮内 spinner，表单禁用。
- Error：字段级错误 + 顶部错误摘要；焦点移到摘要。
- Offline：顶部横幅“当前离线，无法登录”；保留输入。

**可访问性**

- 每个输入有可见 `<label>`；`autocomplete="email"` / `current-password` / `new-password`。
- 错误用 `aria-describedby` 关联字段；错误摘要 `role="alert"`。
- 提交按钮不在表单无效时禁用（点击后显示错误），避免隐藏问题。

### 3.2 Dashboard

**目标**：5 秒内回答“今天该做什么”，并展示近期状态。

**桌面布局**

```text
┌ 今日复习 ────────────────────────────────┐
│ 12 个技能到期   预计 18 分钟   [开始复习] │
└──────────────────────────────────────────┘
┌ 快速开始 ───────────┐ ┌ 近期表现 ────────┐
│ 算法识别 / 模板复现  │ │ 7 天完成 18 次    │
│ 变体复现 / 针对性纠错│ │ 正确率 78%       │
└─────────────────────┘ │ 提示依赖 1.8/5   │
┌ 复习状态 ───────────┐ └──────────────────┘
│ 今日 12 / 逾期 3 / 未来 7 天 24 │
└─────────────────────┘
┌ 继续上次训练（若有） ────────────────────┐
```

**信息**

- 今日到期数量、逾期数量、预计用时。
- 四类训练入口（识别/模板/变体/纠错），显示各自最近一次训练时间或“未开始”。
- 近 7 天：完成 Session 数、正确率、独立完成比例、提示依赖。
- 复习状态：今日/逾期/未来 7 天。
- 继续上次未完成 Session（若有）。

**操作**

- 主操作：`开始复习` → `/review`。
- 快捷入口 → `/practice?type=...` 或直接创建对应类型任务。
- 继续上次 → 恢复 Session。
- 查看全部 → `/analytics`。

**状态**

- 无到期：卡片显示“今天没有到期复习”，主操作变为 `自由练习`；不得显示假数据。
- 新用户无记录：显示 3 步引导（浏览算法库 → 完成首次识别 → 了解复习机制），主操作 `浏览算法库`。
- Loading：4 个骨架卡片；Error：卡片内“加载失败，重试”；Offline：顶部横幅，展示上次缓存数据并标注“可能不是最新”。

**规则**

- 不展示 FSRS Difficulty/Stability。
- 正确率等指标带 tooltip：口径、时间范围、样本量。
- 数据不足（n<3）显示“样本不足”，不显示百分比。

### 3.3 Algorithm Library

**目标**：快速找到算法/技能，理解学习路径。

**桌面布局**

- 顶部：标题、搜索框、排序（分类/难度/最近训练）。
- 左侧筛选栏 240px：分类、难度、技能类型、学习状态（未开始/有到期/已训练）。
- 主区：算法卡片网格（2–3 列）或列表切换。

**算法卡片**

- 名称、分类、难度（1–5 点/标签）、技能数、已训练技能数。
- 到期徽标（若有）。
- 操作：`查看技能`（整卡可点）。

**操作**

- 搜索：按算法/技能名，输入即筛选（300ms debounce）。
- 筛选：多选；显示已选条件 chips；`清除全部`。
- 排序：分类顺序、难度、最近训练。

**状态**

- Loading：卡片骨架。
- 空搜索：`没有匹配的算法` + 清除筛选。
- 无内容：`内容准备中`（正常种子数据不应出现）。
- Error：列表区错误 + 重试；筛选栏保持可用。
- 移动端：筛选变抽屉；卡片单列；搜索固定在顶部。

### 3.4 Algorithm Detail（算法详情）

**目标**：理解算法、查看技能拆分、进入训练。

**布局**

- 头部：名称、分类、难度、摘要、`开始识别训练` 主操作。
- 内容区：
  - 概览（Markdown）。
  - 技能列表：按 skill_type 分组；每项显示名称、目标、掌握证据、到期状态、`训练` 按钮。
  - 前置知识、常见错误（折叠面板）。
  - 相关任务（按训练类型分组）。

**状态**

- 技能为空：提示“技能内容准备中”，不显示空按钮。
- 到期技能：显示“有到期复习”徽标，点击进入 Smart Review 对应技能（若有队列）。
- Error/404：统一错误页。

### 3.5 Skill Detail

**目标**：理解技能、查看证据与薄弱点、开始正确类型的训练。

**布局**

```text
┌ 技能名 [类型徽标] [到期徽标]        [开始训练] ┐
│ 所属算法 / 难度 / 最近训练时间                  │
├ 左：学习信息 ───────────┬ 右：我的证据 ────────┤
│ 学习目标                │ Skill Score 72       │
│ 掌握证据                │ 样本 8 · 初步数据     │
│ 前置知识                │ 正确率 / 独立比例     │
│ 常见错误                │ 最近 5 次证据时间线   │
├ 训练任务 ───────────────┴──────────────────────┤
│ 识别 / 模板 / 变体 / 纠错 任务列表 + 开始按钮    │
└────────────────────────────────────────────────┘
```

**信息与规则**

- Skill Score 标注“技能表现”，附样本量与“不是 FSRS 难度”。
- 下次复习时间标注“FSRS 调度”，不显示 Difficulty/Stability。
- 证据时间线：Session 类型、结果、最高提示、耗时、OJ 证据（若有）。
- 训练任务按类型分组；只显示可用任务。

**状态**

- 样本不足：`样本不足，先完成 3 次训练`，分数显示 `—`。
- 无任务：`该技能暂无训练任务`。
- Error：右栏错误不阻塞左侧内容；重试。

### 3.6 Smart Review

**目标**：按到期队列高效完成正式复习，默认隐藏答案与模板。

**桌面布局**

- 左栏：队列列表（技能名、所属算法、到期时间、逾期标记），当前项高亮。
- 右栏：当前任务摘要 + 规则说明 + `开始复习`。
- 顶部：今日到期数、已完成/总数、预计用时、`退出复习`。

**流程**

1. 进入页面 → 加载到期队列（按用户时区与每日上限）。
2. 选择/自动进入第一项 → 创建 review Session → 跳转专注模式工作区。
3. 完成后 → 结果页 → `下一项` 返回队列。
4. 队列完成 → 完成状态页，显示下次到期时间。

**隐藏答案规则**

- 工作区不显示参考实现、完整模板、结果页之前不显示目标答案。
- 提示按 1–5 级逐级申请；识别任务只有 1–3 级。
- 结果页提供 `查看参考实现`，需显式点击；点击后记录“已查看参考实现”作为证据备注（不改变历史答案）。

**状态**

- 空队列：`今日复习已完成` + 下次到期时间 + `自由练习`。
- 加载失败：错误 + 重试；不得显示旧队列冒充今日。
- 跨日：页面顶部显示“已跨日，队列已刷新”。
- 离线：禁止开始正式复习（需要服务端创建 Session）；提示恢复网络。

### 3.7 Free Practice

**目标**：自由选择任务练习，默认不更新 FSRS。

**布局**

- 顶部：说明条“自由练习默认不更新复习进度”，信息图标解释规则。
- 筛选栏：分类、算法、技能、训练类型、难度、来源。
- 主区：任务列表/表格（标题、技能、类型、难度、最近训练）。
- 右侧或底部：选中任务预览 + `开始练习`。

**规则**

- 开始前模式徽标明确 `自由练习`。
- 完成时可勾选 `标记为正式复习`（默认关闭）；勾选后说明会更新该技能 FSRS。
- 未勾选的结果页显示“本次未更新复习进度”，并提供 `标记为正式复习` 操作（需幂等）。
- 不做“随机一题”以外的推荐算法；MVP 不引入自适应推荐。

**状态**

- 无匹配任务：清除筛选 / 浏览算法库。
- 加载/错误/离线同全局规则。
- 移动端：筛选抽屉；任务列表单列；开始按钮固定在底部安全区。

### 3.8 Practice Workspace（训练工作区）

**目标**：专注完成一次训练，采集完整证据。

**桌面布局（≥1280px）**

```text
┌ 专注顶栏：任务名 / 类型 / 模式徽标 / 计时 / 本次状态 / 错误类型 ┐
├ 左：题目 320–420px ───────────┬ 右：作答区 flex ──────────────────┤
│ 题面 / 约束 / 目标技能        │ 识别：多选算法                    │
│ 参考实现提示                  │ 模板/变体/纠错：Monaco            │
│ 提示抽屉（默认关闭）           │ 提交按钮                          │
└───────────────────────────────┴───────────────────────────────────┘
```

**顶栏**

- 返回/退出：若有未提交内容，弹确认“退出后保留草稿？”。
- 模式徽标：`正式复习`（强调色）或 `自由练习`（中性）。
- 计时：从 Session 开始计时；显示 `mm:ss`；不在每秒触发屏幕阅读器播报。
- `本次状态`：右上角按钮，打开浮层显示模式、状态、最高提示、难度。
- `错误类型`：右上角按钮（任务配置了错误类型时显示），打开浮层多选。
- 作答区提供 `Vim 模式 ON/OFF` 开关；开启后 Monaco 使用 Vim 键位并在底部显示 `-- NORMAL --` / `-- INSERT --` 状态栏。
- 自评已移除；编码任务提交后由系统自动判题。

**任务面板**

- Markdown 渲染（白名单），代码块可复制。
- 折叠“约束/示例/目标技能”。
- 正式复习时隐藏参考实现与完整模板。

**作答区**

| 训练类型 | 交互 |
|---|---|
| 算法识别 | 可搜索多选算法/技能；已选 chips；`提交识别`；提交后立即显示正确/部分/错误与目标算法（结果页再展示完整解释）。 |
| 模板复现 | Monaco 编辑器（C++17）；初始脚手架；`重置为初始代码`（需确认）；`提交代码`。 |
| 变体复现 | 同模板，但展示基础模板/变体要求；编辑器初始为脚手架或空白。 |
| 针对性纠错 | 左侧只读缺陷代码 + 右侧可编辑修复区（或单编辑器初始为缺陷代码）；错误类型标签；`提交修复`。 |

**提交前自动判题（编码类）**

- 编码任务提交后，后端在受限 Docker 容器中编译并运行内置测试用例。
- 结果：通过 / 部分通过 / 未通过 / 编译错误 / 运行错误 / 超时；不需要用户自评。
- 结果页展示通过数、测试输入、期望输出与实际输出；OJ 证据仍作为独立外部证据。

**测试运行与 AI 判题（编码类）**

- 测试运行面板默认展开题目样例用例，可添加自定义输入/期望输出；运行只判当前代码，不提交会话。
- AI 判题面板把题面、约束、参考实现和当前代码交给 LLM，展示结论、分数、问题与建议；未配置密钥时提示不可用。

**草稿与编辑器高度（编码类）**

- 作答内容自动保存到服务端草稿（700ms 防抖），刷新页面、关闭浏览器重开都恢复草稿。
- 新建 Session（包括进入正式复习）从题目模板开始；只有复习开始时才重置为模板。
- `格式化（回到模板）` 一键恢复当前题目的初始模板，并立即保存为草稿。
- `历史代码` 展示该 Session 上一次提交的代码，可一键填回编辑区。
- 编辑器默认 560px 高，可拖动底部分隔条或聚焦后用 ↑/↓ 调整，高度保存在本地，下次进入沿用。

**提示面板**

- 位于题目面板底部，使用抽屉式 `<details>`，默认关闭。
- 展开后显示 0–5 级提示按钮；未解锁等级显示锁图标；识别任务只到 3。
- 点击 `申请提示` → 确认“使用提示会记录为独立程度证据” → 展示内容并记录。
- 已使用提示不可撤销；最高提示等级实时显示在抽屉标题。

**提交状态**

- 提交中：按钮 loading，禁用重复提交。
- 成功：跳转结果页。
- 409：`本次会话已完成`，刷新状态并跳转结果页。
- 网络失败：保留草稿，显示重试；不得假装成功。
- 离线：提交禁用，草稿本地保存；恢复后重试。

**响应式**

- 1024–1279px：两栏变单栏；题目面板取消 sticky，提示抽屉保留。
- <768px：题目 / 作答纵向排列；右上角按钮换行；底部提交栏保持可见。
- 编辑器最小高度 320px；移动端 50vh；字体不小于 16px 以防 iOS 聚焦缩放。

**可访问性**

- Monaco 开启屏幕阅读器支持；提供“切换到纯文本编辑”兜底。
- 提示、提交结果、错误使用 live region。
- 快捷键：`Ctrl/Cmd + Enter` 提交（需确认弹窗），`Esc` 关闭弹窗；不与编辑器快捷键冲突。

│ 测试用例输入/期望/实际                │ [再练一次] [查看技能]     │

│ 提示使用时间线                       │                          │
│ 错误类型                             │                          │
├ 参考实现（默认折叠） ────────────────┴──────────────────────────┤

**信息与规则**

- 结果徽标同时用图标 + 文案 + 颜色。
- 自动判题结果与 OJ 证据分列，来源徽标：`内置判题`、`OJ 手动关联`。
- 编译错误展示编译器输出；测试用例展示输入、期望输出、实际输出。

- 参考实现默认折叠；点击后展示并记录查看事件。

- `再练一次` → 创建同任务 free Session。
- `返回复习队列` → `/review`（review 模式）。
- `查看技能` → Skill Detail。
- `返回 Dashboard`。

**状态**

- 加载失败：错误 + 重试；不要用本地推测结果。
- 已被其他标签页完成：刷新到最新结果，提示“本次结果已更新”。
- 无 OJ 证据：不显示空卡片，显示轻量提示与关联入口。

### 3.10 Analytics

**目标**：可信、可解释地展示训练表现与复习状态。

**布局**

- 顶部：时间范围（7/30/90 天/自定义）、训练类型筛选、算法/技能筛选、样本量徽标。
- KPI 行：完成次数、正确率、独立完成比例、提示依赖、平均归一化耗时、到期复习数。
- 图表区：
  - 趋势：正确率/独立比例随时间的折线。
  - 训练类型分布：堆叠柱。
  - 错误类型分布：横向条形。
  - 提示等级分布：柱状。
  - 复习状态：今日/逾期/未来 7 天。
- 表格：Skill Score 列表（技能、分数、样本量、状态、最近训练）。
- 指标定义区：每个指标的公式、来源、时间范围。

**规则**

- 每个指标有 tooltip/定义链接；没有定义不展示。
- 样本不足（n<3）显示 `—` 与“样本不足”；n<10 显示“初步数据”。
- 耗时只显示“相对个人基准”的归一化值，不跨算法绝对比较。
- 不展示 FSRS Difficulty/Stability；复习状态只展示到期/逾期/未来。
- Dashboard 与 Analytics 的数字必须同源；不得使用 mock 数据。

**状态**

- 无数据：说明“当前时间范围没有完成记录”，提供 `开始训练`。
- 部分数据：图表显示但标注“样本不足”；不隐藏。
- Error：单图表错误不影响其他图表；提供重试。
- 离线：展示上次数据并标注时间；不自动刷新。

**响应式**

- 图表单列堆叠；KPI 两列；表格横向滚动或卡片化。
- 移动端时间范围变下拉；筛选抽屉。

### 3.11 Settings

**目标**：安全管理账号、复习偏好与 OJ 关联。

**布局**

- 左侧子导航：个人资料、复习偏好、OJ 账号、安全。
- 右侧表单区，分组卡片（每组一个 `<fieldset>`）。

**个人资料**

- 显示名、邮箱（只读）、主题（深色/浅色/跟随系统）、语言（MVP 中文）。
- 保存/取消；未保存离开提示。

**复习偏好**

- 时区（IANA 下拉 + 搜索）。
- 每日复习上限（数字 1–500，默认 50）。
- 目标保留率（高级项，0.70–0.99，默认 0.90）；解释“数值越高，复习越频繁”，不称为能力。
- 修改时区提示：“会影响今日复习边界与到期队列”。

**OJ 账号**

- 列表：平台、handle、状态、`移除`。
- 添加：平台选择、handle；MVP 不要求密码。
- 说明：MVP 仅支持手动关联提交与题目跳转，不同步提交。
- 移除需确认；不影响已关联 Submission。

**安全**

- 修改密码（当前密码 + 新密码 + 确认）。
- `退出所有设备`（撤销所有会话）。
- 不显示会话 token。
- 危险区域：账号删除，要求当前密码 + 输入 `DELETE` 确认；成功后清除 Cookie 并回到登录页。

**数据与隐私**

- 导出 JSON：训练 Session、复习记录、OJ 与统计数据，不含密码/Token/IP 哈希。
- 删除账号会级联清理训练、复习、OJ、统计与登录数据，不可恢复。

**状态**

- 保存成功 toast；字段错误 inline + 摘要；网络错误保留输入。
- 时区/上限变更后，Dashboard 到期数需要刷新；显示“已更新，正在刷新”。
- 未保存变更离开确认。

## 4. 通用状态设计

每个页面/组件必须覆盖以下状态，不能只做“有数据”版本。

| 状态 | 表现 | 操作 |
|---|---|---|
| Loading | 骨架屏优先于 spinner；超过 300ms 才显示 | 无 |
| Empty | 说明“这里是什么/为什么为空” + 下一步动作 | 主操作 |
| Error | 具体原因 + 重试 + request_id（500 时） | 重试/返回 |
| Offline | 顶部横幅“当前离线”；读展示缓存并标注时间；写禁用 | 重连后重试 |
| No data | 与 Empty 区分：时间范围/筛选导致 | 调整范围/清除筛选 |
| Partial | 部分模块失败，其他模块可用 | 局部重试 |
| Disabled | 说明为什么不可用（工具提示/旁注），不只变灰 | 解除条件 |
| Overflow | 长标题截断 + tooltip；表格横向滚动；代码换行 | 查看完整 |
| 401 | 跳转登录并保留 return URL | 登录 |
| 403 | 无权访问，不泄露资源存在性 | 返回 |
| 404 | 找不到页面/资源 | 返回 Dashboard |
| 409 | 状态冲突，刷新到最新状态 | 刷新 |
| 429 | 限流倒计时 | 等待 |
| 500 | 错误页 + request_id + 重试 | 重试/反馈 |

**离线策略（MVP）**

- 只读页面：可展示上次成功数据，必须标注“数据截至 HH:mm，可能不是最新”。
- 写操作：禁止提交正式复习、Session 完成、OJ 关联；草稿保存在本地，恢复网络后允许重试。
- 不使用 Service Worker 做完整离线应用；MVP 只做网络状态提示与草稿保护。

## 5. 关键交互规则

### 5.1 正式复习 vs 自由练习

| 交互点 | 正式复习 | 自由练习 |
|---|---|---|
| 入口 | Dashboard / Smart Review | Free Practice / Dashboard 快捷 |
| 模式徽标 | `正式复习`（强调色） | `自由练习`（中性） |
| 答案可见性 | 默认隐藏参考实现/模板 | 可查看（仍不主动展示答案） |
| 提示 | 可用，记录独立程度 | 可用，记录证据 |
| FSRS | 完成后更新 | 默认不更新；完成时可标记 |
| 结果页 | 显示下次复习时间 | 显示“未更新复习进度” |

### 5.2 提示

- 等级文案：0 无提示；1 算法类别；2 核心思想；3 数据结构/状态；4 部分代码；5 完整参考实现。
- 识别任务只显示 1–3。
- 每次申请需确认；记录等级、时间、内容快照。
- 最高提示等级实时显示在顶栏/结果页。
- 不提供“一键显示答案”；参考实现只在结果页显式展开。

### 5.3 计时

- 从 Session 创建/开始计时；服务端时间为准，客户端只做展示。
- 页面隐藏不暂停（作为证据，不作为考试）。
- 超过 2 小时恢复时提示“会话已放置较久，是否继续或放弃？”；继续则保留原 Session。
- 结果页显示总用时；不计入网络等待时间（以服务端 `started_at`/`completed_at` 为准，后续可细化）。

### 5.4 提交与幂等

- 提交按钮点击后立即禁用，显示 loading。
- 重复提交由服务端幂等键保护；409 时刷新结果。
- 网络失败不显示成功；保留草稿并提供重试。
- 结果页刷新不重复更新 FSRS。

### 5.5 自动判题与 OJ 证据

- 编码类提交后由后端自动判题，不再弹出自我评价表单。
- 自动判题结果与 OJ 证据分列展示，不互相覆盖。
- 判题失败/超时/编译错误必须展示具体状态，不能伪装成通过。
- OJ 手动关联字段：平台、提交 ID、题目引用/URL、Verdict、语言、耗时、内存、提交时间；MVP 不调用 OJ API。
- 重复关联同一 `(platform, external_id)` 提示“已关联”，不创建重复记录。

### 5.6 键盘与快捷键

- `Ctrl/Cmd + K`：全局搜索。
- `Ctrl/Cmd + Enter`：提交代码并触发自动判题。
- `Esc`：关闭弹窗/抽屉；不直接退出工作区。
- `?`：快捷键帮助（可选，阶段 7 实现）。
- 所有图标按钮有 `aria-label`；所有弹窗焦点陷阱与恢复。

| `text-muted` | `oklch(0.50 0.010 70)` | `oklch(0.70 0.008 70)` | 次要文本 |

规则：

- 主按钮文字颜色按对比度选择 `on-accent`（深色或白色），阶段 7 验证。
- 语义色不用于装饰；正确/错误同时有图标与文字。
- 深色模式提高 line-height 与字重，补偿光学变细。

### 6.2 字体与字号

| Token | 值 | 用途 |
|---|---|---|
| `font-ui` | `Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif` | 界面 |
| `font-mono` | `"JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, monospace` | 代码 |
| `text-xs` | 12px / 1.4 | 徽标/辅助 |
| `text-sm` | 13px / 1.5 | 表格/次要 |
| `text-base` | 14px / 1.6 | UI 基础 |
| `text-md` | 16px / 1.7 | 正文阅读 |
| `text-lg` | 18px / 1.5 | 小标题 |
| `text-xl` | 20px / 1.4 | 页面区块标题 |
| `text-2xl` | 24px / 1.3 | 页面标题 |
| `text-3xl` | 30px / 1.2 | 关键数字 |
| `text-4xl` | 36px / 1.1 | Dashboard 大数字 |

正文 measure：60–76ch；长文 68ch；训练题面最大 72ch。

### 6.3 间距、圆角、阴影

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64；组件内 4/8/12，区块间 24/32/48。
- 圆角：6px（输入/小按钮）、10px（卡片）、14px（大面板/弹窗）、full（头像/徽标）。
- 阴影：`shadow-sm` 卡片悬浮；`shadow-md` 弹窗；避免厚重投影。
- 边框优先于阴影；1px `border` 足够分层。

### 6.4 动效

- `fast` 120ms、`base` 180ms、`slow` 240ms；缓动 `cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 只动 `transform`/`opacity`；高度变化用 grid rows。
- 页面切换 120ms 淡入；弹窗 180ms；退出 70% 时长。
- `prefers-reduced-motion`：全部降为即时或 100ms 淡入；不在结果页做庆祝动画。

### 6.5 栅格与断点

| 断点 | 布局 |
|---|---|
| ≥1440 | 内容最大 1440；侧栏 240；工作区两栏（题目 + 作答） |
| 1280–1439 | 内容自适应；侧栏 240；工作区两栏 |
| 1024–1279 | 侧栏 72 图标；工作区单栏；提示抽屉保留 |
| 768–1023 | 抽屉导航；单栏；筛选抽屉 |
| <768 | 单列；底部操作栏；表格卡片化 |
| <480 | 最小支持 320px；字号/触控目标不缩小 |

## 8. 指标与图表口径（UI 展示层）

> 完整公式在阶段 12 `docs/ANALYTICS_METRICS.md` 固化；此处锁定展示方式。

| 指标 | 展示 | 说明 |
|---|---|---|
| 到期复习数 | 大数字 + “预计用时” | 用户时区、每日上限后的队列 |
| 完成 Session 数 | 数字 + 趋势 | 按时间范围 |
| 正确率 | 百分比 + 样本量 | 自动判题与识别判分；OJ 证据独立 |
| 遗忘曲线 | 折线图 | Fibonacci 计划（1/1/2/3/5/8/13/21 天）vs 我的 FSRS 稳定度曲线 |
| 独立完成比例 | 百分比 | 最高提示 ≤1 的 Session 占比 |
| 提示依赖 | 0–5 分或百分比 | 平均最高提示等级，越高依赖越强 |
| 归一化耗时 | 相对个人基准 | 不跨算法绝对比较 |
| 错误类型分布 | 横向条形 | 来源：Session.error_types |
| 训练类型分布 | 堆叠柱 | 四类训练分开 |
| Skill Score | 0–100 + 样本量 | 与 FSRS 无关；n<3 显示样本不足 |
| 复习状态 | 今日/逾期/未来 7 天 | 不显示 FSRS 参数 |

图表要求：

- 每个图表有标题、时间范围、样本量、空状态。
- 颜色使用语义 token；不同训练类型用形状/标签辅助，不只靠颜色。
- Tooltip 显示原始数值与口径。
- 图表数据必须与底层记录一致；不使用假数据。

## 9. 文案规范

- 语言：MVP 中文；代码/算法名保留英文。
- 句式：句首大写仅英文；中文不加句号标题。
- 按钮：一个动词，命名动作：`开始复习`、`提交答案`、`申请提示`、`查看参考实现`、`手动关联 OJ 提交`。
- 不使用：`确定`、`提交`（单独使用）、`OK`、`是/否` 作为主按钮。
- 错误：说清“发生了什么 + 下一步”，不指责用户。
- 不用感叹号；不用破折号堆叠；不用“轻松/一键/智能”等空泛词。
- 不用“已掌握”描述单次 AC；用“本次结果”“本次证据”“技能表现”。
- FSRS：用“下次复习”“复习调度”，不用“难度值/稳定性”。

## 10. 可访问性（WCAG AA）

- 语义结构：`header/nav/main/aside/footer`；页面唯一 `h1`；标题层级不跳级。
- 键盘：所有交互可 Tab 到达；焦点顺序符合视觉；弹窗焦点陷阱并恢复；`Esc` 关闭。
- 焦点：`:focus-visible` 2–3px 环，3:1 对比；禁止无替代的 `outline: none`。
- 表单：可见 label；错误 `aria-describedby`；错误摘要 `role="alert"`；不用 placeholder 代替 label。
- 动态：提示展示、提交结果、计时里程碑用 live region；不要每秒播报计时。
- 颜色：对比度 ≥4.5:1（正文）/3:1（大字/图形）；状态不只用颜色。
- 触控：最小 44×44px；移动端输入字号 ≥16px。
- 缩放：200% 缩放不破版；320px 宽可重排；不使用固定高度锁死文本。
- 动效：尊重 `prefers-reduced-motion`；不自动播放循环动画。
- Monaco：开启屏幕阅读器支持；提供纯文本兜底；编辑器外有“提交/提示”可键盘操作。

## 11. 响应式规则

| 区域 | 桌面 | 平板 | 手机 |
|---|---|---|---|
| 导航 | 侧栏展开 | 侧栏图标/抽屉 | 顶部菜单 + 抽屉 |
| Dashboard | 2–3 列卡片 | 2 列 | 单列 |
| Library | 筛选栏 + 2–3 列 | 筛选抽屉 + 2 列 | 单列 + 抽屉 |
| Skill Detail | 左右两栏 | 上下堆叠 | 单列 |
| Review | 队列 + 详情两栏 | 队列抽屉/上下 | 单列队列 |
| Workspace | 两栏（题目 + 作答） | 单栏 + 提示抽屉 | 单栏 + 底部操作栏 |
| Result | 两栏 | 单列 | 单列 |
| Analytics | 多图网格 | 2 列 | 单列 + 横向滚动表格 |
| Settings | 子导航 + 表单 | 子导航 + 表单 | 子导航抽屉/分段 |

其他规则：

- 触屏用 `pointer: coarse` 增大点击区域；不把功能藏在 hover。
- 表格在窄屏转卡片列表或横向滚动，不截断关键字段。
- 代码编辑器在移动端全宽、50vh；工具栏按钮不重叠。
- 底部固定操作栏使用 `env(safe-area-inset-bottom)`。

## 12. 页面验收清单

- [ ] 登录/注册：错误、限流、loading、键盘提交可用。
