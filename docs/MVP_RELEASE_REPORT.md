## 1. 发布摘要

MomoCode MVP 已完成核心闭环：

```
注册/登录 → 算法库 → 四类训练 → 证据记录 → FSRS 正式复习
→ 到期队列 → OJ 手动关联 → Analytics → Settings
```

本次评审基于：

- PRD v1.0、架构 v1.0、数据库 v1.0、UI/UX v1.0、内容规范 v1.0。
- 后端 29 个自动化测试。
- 前端 ESLint、vue-tsc、2 个组件测试、生产构建。
- 真实 PostgreSQL/Redis、生产 Compose、Nginx、浏览器 E2E。
- 数据库备份/恢复演练。

## 2. 已交付能力

### 2.1 产品与内容

- 3 个算法分类、10 个初始算法、40 个技能、40 个训练任务；每个算法覆盖四类训练。
- 10 个算法均覆盖识别、基础实现、变体、常见错误四类技能，并各有四类训练任务。
- 内容版本、checksum、幂等导入与 `--force` 重放。

### 2.2 训练与复习

- 四类训练：识别自动判分、模板复现、变体复现、针对性纠错。
- Session 生命周期、分级提示、计时、Docker 自动判题、OJ 证据分离、错误类型。
- FSRS 6.3.2：user × skill 记忆状态、正式复习更新、自由练习默认不更新、幂等。
- 到期队列、今日统计、每日上限、用户时区。
- 结果页展示证据与下次复习时间。

### 2.3 OJ 与 Analytics

- OJ 账号元数据、手动 Submission、Session 关联、幂等、URL 白名单。
- `OJAdapter` 契约与 Manual Adapter；不做 OJ API 同步（MVP 范围）。
- Analytics：正确率、独立比例、提示依赖、归一化耗时、训练类型/错误分布、复习状态、Skill Score v0。
- 指标定义 API 与页面；样本不足标注；无假数据。

### 2.4 工程与安全

- 模块化单体：FastAPI + SQLAlchemy async + Alembic。
- Vue 3 + TypeScript + Vite + Pinia + Router + Monaco + ECharts。
- Nginx 同源静态资源与 API 代理；CSP 与安全响应头。
- Argon2id、HttpOnly 会话 Cookie、CSRF、Redis 限流、用户隔离。
- 生产 Docker Compose、镜像构建、健康检查、备份/恢复脚本。
- 生产依赖审计 0 漏洞。

## 4. 公网发布前置条件

以下为部署配置项，**不是代码功能缺失**；未完成前不建议直接对公网开放：

1. 配置 TLS/HTTPS（443 + HTTP 重定向）。
2. 生产 Secrets：强 `SESSION_SECRET`、数据库密码、`ENVIRONMENT=production`、`SESSION_COOKIE_SECURE=true`。
3. `CORS_ORIGINS` 改为真实 HTTPS 域名。
4. 配置每日定时备份 + 异地保存 + 恢复演练。
5. 配置 uptime 监控与告警（`/health/ready`、`/`、5xx、登录失败、磁盘）。
6. 发布前复核依赖审计与安全公告。

## 5. 已知限制

- 已支持邮箱验证、找回密码、修改密码、活跃会话管理与账号删除（密码 + `DELETE` 确认）。
- 无第三方登录（预留 Provider 抽象）。
- 无 OJ 提交同步的完整多平台支持；已支持 Codeforces 手动同步与手动关联。
- 无提醒/通知；已支持 JSON 数据导出与主题偏好同步。
- 单实例部署；多实例需独立迁移 Job 与共享基础设施。
- Monaco 编码页 chunk 仍约 2.7MB，但已改为仅编码任务异步加载；Analytics 已按需引入 ECharts，主包约 545KB。
- 登录限流在 Redis 故障时 fail-open。
- Vitest 3 开发依赖有 2 个 critical 审计项（生产包不受影响）；建议后续升级测试栈。
- Playwright E2E 已纳入 CI（Postgres/Redis 服务 + Chromium），覆盖主训练闭环、账号删除与修改密码。
- UI 采用深色夜间工业风（近黑炭灰 + 橙色强调），默认深色；浅色仍可切换。
- 用户时区/偏好与主题已支持后端同步；移动端仍可继续优化。

## 6. 风险评估

| 风险 | 等级 | 说明 | 缓解 |
|---|---|---|---|
| 公网未配 TLS | 高 | 会话 Cookie 需 Secure；明文 HTTP 不安全 | 发布前配置 HTTPS，强制 Secure |
| 备份未定时/异地 | 高 | 数据丢失风险 | 定时任务 + 异地存储 + 演练 |
| 无外部监控 | 中 | 故障发现依赖用户反馈 | 上线前接入 uptime/告警 |
| 限流 fail-open | 中 | Redis 故障时暴力破解防护减弱 | 监控 Redis；后续 fail-closed/本地限流 |
| 前端产物体积 | 中 | Monaco 编码页仍约 2.7MB | 已仅在编码任务异步加载；ECharts 已按需引入；后续继续裁剪 |
| 开发依赖审计 | 中 | 测试工具链漏洞 | 不影响生产；后续升级 Vitest 5 |
| 单实例 | 中 | 无高可用 | 后续托管数据库/多副本 |
| 内容规模有限 | 低 | 目前 10 个算法、40 个任务 | 后续继续扩展算法与变体 |

6. **质量**：Playwright E2E 已纳入 CI；继续提升前端组件测试覆盖率。
7. **运维**：多实例部署、托管数据库、集中日志/指标/告警。
