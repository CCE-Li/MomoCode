# Code Template Training

定义“怎么练”：把代码模板拆成可训练单元，并设计填空、无提示复现与限时编码训练的机制与判定。

## 职责范围

- 代码模板拆解为可训练单元。
- 代码填空训练形式。
- 无提示复现训练形式。
- 限时编码训练形式与判定标准。

## 触发时机

- 设计模板拆解流程。
- 设计填空题目或复现任务。
- 设计限时编码训练。
- 定义训练任务的判定标准（通过 / 部分 / 失败）。

## 工作流程

1. 选择模板，拆解为可训练单元。
2. 依据单元生成填空或复现任务。
3. 定义提示递减规则。
4. 定义限时规则。
5. 定义判定标准与反馈方式。

## 边界与禁止

- 只管“训练形式与判定”，不决定训练计划或难度。
- 训练计划与难度调整 → `adaptive-learning`；耗时 / 错误率等指标统计 → `coding-performance`。
- 不臆造未确认的训练能力或依赖。

## 输出物

- 训练形式定义。
- 任务生成规则。
- 判定标准与反馈规则。
