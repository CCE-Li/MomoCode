# Algorithm Taxonomy

定义 MomoCode 的算法知识组织方式：知识点体系、外部 OJ Tag 到内部知识点的映射，以及知识点之间的关联。

## 职责范围

- 算法分类原则与知识点体系。
- 外部 OJ Tag 到内部知识点的映射规则。
- 知识点之间的关系（前置 / 相关）。
- 知识体系的版本化与维护规则。

## 触发时机

- 设计或维护算法标签、知识点树。
- 定义或修正题目归类规则。
- 建立 OJ Tag 与内部知识点的映射。
- 定义知识点之间的前置 / 相关关系。

## 工作流程

1. 定义分类原则：明确是层次结构还是扁平、是否允许多标签。
2. 构建知识点结构。
3. 制定外部 Tag → 内部知识点的映射规则，包含未知 Tag 的处理方式。
4. 定义知识点之间的关系（前置、相关）。
5. 定义版本化与维护规则（新增、合并、废弃标签如何演进）。

## 边界与禁止

- 只管“知识如何组织”。
- 掌握度评估 → `spaced-repetition`；难度与排期 → `adaptive-learning`；数据抓取 → `oj-integration`。
- 不臆造具体 OJ 的 Tag 列表，须有来源或标 `TODO(确认来源)`。

## 输出物

- 知识体系结构。
- Tag 映射规则。
- 知识点关系定义与维护规范。

## 反虚构约定

外部 OJ、平台或库的真实字段、标签、端点、参数在无确认来源前一律不写死；不确定处标注 `TODO(确认来源)`。

## references 使用

当标签规范或映射表较长时，放入本 Skill 的 `references/`（如 `references/tag-mapping.md`），并在正文用相对路径引用。
