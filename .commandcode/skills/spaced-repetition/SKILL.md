# Spaced Repetition

基于 FSRS 的复习调度层：决定每个复习对象“何时该复习”，并维护其掌握度状态。

## 职责范围

- FSRS 复习周期（间隔与到期时间）。
- 掌握度状态模型与评级输入。
- 到期复习队列的生成。
- 遗忘、重排与重置规则。

## 触发时机

- 实现或调整复习间隔计算。
- 安排复习计划或生成到期队列。
- 评估知识点 / 题目的掌握程度。
- 设计或调整复习调度策略。

## 工作流程

1. 定义复习对象（题目或知识点）。
2. 建立掌握度状态模型，明确评级输入（如通过 / 部分 / 失败）。
3. 依据 FSRS 更新间隔与到期时间。
4. 生成到期复习队列。
5. 定义遗忘处理、队列重排与进度重置规则。

## 边界与禁止

- 只做“何时复习”的调度，不决定“复习什么 / 训练什么”。
- 复习内容与训练计划 → `adaptive-learning`；表现数据来源 → `coding-performance`；知识结构 → `algorithm-taxonomy`。
- 不臆造 FSRS 参数：参数须可配置，并有确认出处或标 `TODO(确认来源)`。

## 输出物

- 复习调度规则。
- 掌握度模型。
- 到期队列定义与重排规则。

## 反虚构约定

FSRS 的公式、参数与外部来源在无确认前不写死；不确定处标注 `TODO(确认来源)`。
