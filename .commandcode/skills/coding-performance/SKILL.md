# Coding Performance

定义训练表现的“指标口径”，并负责统计，为自适应学习提供数据。

## 职责范围

- 指标口径定义（耗时、错误率、代码复现能力、训练表现）。
- 指标的采集触发与聚合方式。
- 表现报表的生成。

## 触发时机

- 定义或修改训练指标。
- 采集或统计编码表现数据。
- 生成训练表现报表或分析。

## 工作流程

1. 定义指标口径：含义、单位与采样点。
2. 定义采集触发点。
3. 定义聚合与统计方式。
4. 生成报表，并输出给 `adaptive-learning` 消费。

## 边界与禁止

- 只负责定义与统计，不做调度或决策。
- 训练形式与判定 → `code-template-training`；任务调度 → `adaptive-learning`。
- 不臆造未确认的指标来源或外部数据。

## 输出物

- 指标字典（口径说明）。
- 统计算法说明。
- 报表结构。

## 反虚构约定

外部 OJ、平台或库的真实字段、端点、参数在无确认来源前一律不写死；不确定处标注 `TODO(确认来源)`。
