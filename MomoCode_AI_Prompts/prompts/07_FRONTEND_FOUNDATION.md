# 阶段 7：前端基础设施

先检查仓库和 UI/UX 文档。

## 目标
建立可扩展 Vue Web 应用，不填充大量假业务数据。

## 工作
配置 Vue 3、TypeScript、Vite、Router、Pinia、Layout、导航、API Client、统一错误处理、类型组织、设计 token、基础组件、登录状态接口、页面骨架和测试工具。按实际需要再集成 Monaco Editor、ECharts。

## 约束
API 请求不得散落在页面；不得用大量 mock 冒充真实功能；本阶段不实现完整训练业务；避免过度抽象。

## 验收
路由、Layout、API 健康检查正常；类型检查、Lint 和测试通过；有基本加载、错误和空状态。
