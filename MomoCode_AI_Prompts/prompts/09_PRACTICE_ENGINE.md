# 阶段 9：训练引擎

先阅读内容规范、数据库设计和 API 架构。

## 目标
实现训练任务创建、开始、交互、提交和结果记录；本阶段不接真实 FSRS，也不依赖真实 OJ 自动同步。

## 工作
实现任务查询筛选、PracticeSession 生命周期、四种训练流程、开始/结束时间、答案和完成状态、分级提示记录、自评与客观证据分离、错误类型记录、结果摘要，以及正式复习/自由练习标记。

## 约束
OJ Verdict 只是证据；不能混淆自评和系统验证；不写死 FSRS 规则；关键状态转换必须测试。

## 验收
四类训练可完成；提示记录准确；Session 与 Skill 关联正确；自由练习默认不更新记忆；非法状态转换被拒绝。
